# ai-sandbox

> Sandbox personal de experimentación con IA, LLMs y agentes.
> Autor: Eduardo Castillo (MrCastilloF) | Inicio: 2026-04-27

---

## Objetivo

Este repositorio es mi laboratorio privado para explorar, probar y documentar experimentos con:
- Modelos de Lenguaje Grande (LLMs)
- Agentes autónomos de IA
- Ingeniería de prompts
- Herramientas de desarrollo asistido por IA
- Integraciones con APIs (OpenAI, Ollama, LangChain, etc.)

---

## Estructura del repositorio

```
ai-sandbox/
├── projects/       # Proyectos con estructura definida y objetivo claro
├── experiments/    # Experimentos rápidos, pruebas de concepto, sketches
├── prompts/        # Biblioteca de prompts reutilizables y plantillas
├── docs/           # Documentación técnica, guías y referencias
├── logs/           # Trazabilidad de ejecuciones y resultados
├── history.md      # Registro cronológico: qué probé, qué funcionó, qué falló
├── .gitignore      # Exclusiones Python + entornos virtuales
└── README.md       # Este archivo
```

---

## Convenciones de commits

```
feat:   nueva funcionalidad o experimento
fix:    corrección de errores
docs:   documentación
test:   pruebas
```
